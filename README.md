# AozoraEpub3-to-azw3

[English](README.md) | [日本語](README.ja.md)

A Rust library and CLI for converting EPUB files generated by
[AozoraEpub3](https://github.com/kyukyunyorituryo/AozoraEpub3)
into KF8-only AZW3 files.

Support for
[AozoraEpub3_Lite](https://github.com/Rumia-Channel/AozoraEpub3_Lite)
is also planned.

It focuses on Japanese vertical writing, right-to-left progression,
ruby, emphasis marks, and Kindle-oriented CSS projection.

It is not a general EPUB converter or a full KindleGen replacement.

Requires Rust 1.85 or newer.

```bash
cargo install aozora_epub3_to_azw3
```

## Quick Start

Convert an EPUB:

```bash
AozoraEpub3-to-azw3 input.epub
```

The output path defaults to the input path with its extension replaced
by `.azw3`.

## Why

KindleGen has been unavailable from Amazon for many years and is no
longer a practical dependency for new tooling.

This project provides a maintained Rust library and CLI for converting
EPUB files directly to KF8-only AZW3.

It intentionally does not generate legacy MOBI7/KF8 dual-format files.
Kindle devices earlier than Kindle Touch (4th Generation) are outside the
supported scope. For current targets, KF8-only output keeps the implementation
smaller and avoids carrying legacy format complexity that is no longer needed.

Because it is a Rust library as well as a CLI, conversion can run
directly in-process without invoking an external KindleGen executable.

## Compared with KindleGen

| | KindleGen | aozora-epub3-to-azw3 |
|---|---|---|
| Input | EPUB, HTML/OPF, and other supported sources | Supported EPUB |
| Output | Legacy + KF8 Kindle format | KF8-only AZW3 |
| Japanese vertical writing / ruby | Supported | Supported and tested on physical Kindle hardware |
| In-book cover display | Supported | Supported and tested on physical Kindle hardware |
| Kindle library cover thumbnail | Supported | Not currently supported |
| [Devices earlier than Kindle Touch (4th Generation)](https://digprjsurvey.amazon.com/csad/help/node/GK33S847NN4V6Y83) | Supported | Not supported |
| Availability | No longer distributed by Amazon | Open source and actively maintained |

## Performance

The following is one illustrative real-world measurement.

Input preparation:

| Stage | Size |
|---|---:|
| Source TXT (text only, no images) | 49.58 MiB (51,992,309 bytes) |
| AozoraEpub3-generated EPUB | 17.92 MiB (18,789,211 bytes) |

The same generated EPUB was then used as input for both converters:

| | KindleGen | aozora-epub3-to-azw3 |
|---|---:|---:|
| Conversion time | 115.928 s | 4.698 s |
| Output size | 83.70 MiB (87,761,779 bytes) | 47.33 MiB (49,625,944 bytes) |

Each converter was run five times on the same EPUB. Exactly one fastest
run and exactly one slowest run were discarded, and the arithmetic mean
of the remaining three runs is reported for conversion time. In this
measurement, `aozora-epub3-to-azw3` completed the conversion about 24.7x
faster, and the resulting AZW3 was 43.45% smaller than the KindleGen
MOBI.

`aozora-epub3-to-azw3` was run with its default PalmDOC compression.

Results depend on the input, tool versions, and hardware. TXT-to-EPUB
generation time is excluded from the conversion times.

## Supported EPUB generators

- [AozoraEpub3](https://github.com/kyukyunyorituryo/AozoraEpub3) — Supported
- [AozoraEpub3_Lite](https://github.com/Rumia-Channel/AozoraEpub3_Lite) — Planned

Other EPUB generators are outside the supported scope.

## CLI

```text
AozoraEpub3-to-azw3 <input.epub> [-o <output.azw3>] [-c0 | -c1] [-verbose]
    [-dont_append_source] [-donotaddsource]
```

`-c1` is the default and uses PalmDOC compression. `-c0` stores text
records uncompressed. `-dont_append_source` and `-donotaddsource` are
accepted KindleGen-compatibility no-ops; this converter never embeds the
source EPUB. `-c2` (HUFF/CDIC) and unrelated KindleGen options are
intentionally unsupported. When `-o` is omitted, the input extension is
replaced with `.azw3`.

## Library

```rust
use aozora_epub3_to_azw3::{convert_bytes, Compression, ConvertOptions};

let azw3 = convert_bytes(
    &epub_bytes,
    &ConvertOptions { compression: Compression::PalmDoc },
)?;
```

The crate also provides `convert_file(input, output, options)`.

For `convert_file`, output is written directly to the destination file during serialization. It uses no global
mutable conversion state, shared temporary names, current-directory
changes, or internal parallel runtime. Independent conversions are safe
to invoke concurrently. As with ordinary file writing, concurrent
conversions to the exact same output path are the caller's
responsibility.

## Limitations

Kindle devices earlier than Kindle Touch (4th Generation) are not supported.
This converter produces KF8-only AZW3 files intended for that generation and
later.

In-book cover display is supported and has been verified on physical
Kindle hardware.

Kindle library cover thumbnails are not currently supported. In
KF8/AZW3, the cover image contained in the book and the thumbnail used
by the Kindle library are handled separately.

## Validation

Conversion output for AozoraEpub3 EPUBs has been audited against
KindleGen output and checked on physical Kindle hardware, covering EPUB
semantic ingestion, KF8/AZW3 serialization, and end-to-end reading
order, navigation, and text fidelity.

The current A–F audit has completed implementation and verification of the
mandatory contracts, with no known semantic mismatch in the canonical
AozoraEpub3 path.

All 13 reader-visible semantic contracts are covered, and Physical Kindle
Device Evidence is 13 / 13 `CONFIRMED PASS`.

See the [KindleGen semantic parity
audit](docs/KindleGen-Semantic-Parity-Audit.md) for the full results,
methodology, classification criteria, and evidence.
